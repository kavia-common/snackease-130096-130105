# Snack App 3 Frontend

This React app implements the SnackEase experience using the provided Figma-extracted CSS/HTML assets as the primary design reference.

Features
- Authentication (localStorage mock)
- Browse snack catalog with categories
- Snack detail view with size and quantity controls
- Cart / Order details with pricing, taxes, discount
- Place order and view order history (localStorage)

Development
- npm start
- npm run build
- npm test

Notes
- Visuals rely on assets/common.css and the per-screen CSS files imported in App.js.
- Backend integration is out of scope; persistence is localStorage for demo.
